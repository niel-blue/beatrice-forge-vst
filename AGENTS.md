# Repository working rules

## README language synchronization

`README.md` is the canonical Japanese README and remains the default document shown by GitHub.

Whenever the content of `README.md` is changed, update `README_EN.md` in the same change so that the English version preserves the same meaning, features, limitations, build instructions, version information, links, and licensing information. Apply the same rule in reverse when an English README change affects shared content.

Keep the language selector at the top of both files. A README change is not complete until both language versions have been reviewed for consistency.
